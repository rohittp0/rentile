# Migrating from 0.12.x to 0.13.0

`0.13.0` adds opt-in host-owned extrusion geometry. The declaration requests a release; publication
is complete only after the workflow passes and all eight public coordinates resolve. Existing
profiles keep their raster behavior and keys. Existing public constructors and enum ordinals are
unchanged; the ABI additions are two profiles, three interface methods with default unsupported
bodies, and the new extrusion types. Recompile consumers adopting the API.

```kotlin
val style = rasterizer.prepare(input, CompatibilityPolicy.RentileV1HostSymbolsAndExtrusions)
val layers = rasterizer.extrusionLayerDescriptors(style)
val requestKey = rasterizer.extrusionCandidateRequestKey(style, viewportTiles)
val buildings = rasterizer.acquireExtrusionCandidates(
    style, viewportTiles,
    limits = ExtrusionLimits(maxRetainedBytes = 8L * 1024 * 1024),
    resourceAccess = ResourceAccessMode.NORMAL,
)
for (candidate in buildings.candidates) {
    val layer = buildings.layerStyles[candidate.layerStyleIndex]
    val paint = candidate.paintAtZoom(cameraZoom) ?: continue
    val opacity = layer.opacityAtZoom(cameraZoom)
    // Build/use one mesh in candidate.sourceTile and candidate.extent coordinates.
    // candidate.geometry groups each exterior followed by its holes.
    // paint.baseMetres / heightMetres are metres; paint.color is opaque ARGB.
}
```

Use `RentileV1HostExtrusions` to retain the previous symbol rasterization policy. Both new profiles
omit the extrusion raster footprint, including when opacity is zero or height is missing. Ordinary
authored fill layers remain. Styles without extrusion layers return an empty batch. Descriptors
carry authored order, layer/source zoom bounds, source-layer identity and vertical-gradient.

Acquisition includes all visible extrusion layers, independent of the current camera zoom; call
it only for planned windows that need buildings. `paintAtZoom` returns null outside the layer's
inclusive minimum/exclusive maximum zoom or when its integer-zoom filter rejects the feature.
It evaluates height/base/color at fractional zoom; constant paint is cached. Heights/bases default
to zero, negative values clamp to zero, base clamps to height, and color alpha is ignored. Layer
opacity is evaluated separately, clamped to 0..1 and may depend on zoom, not features. Patterns,
translation and other unsupported authored properties fail preparation. There are no fabricated
heights and no automatic shadows or lighting.

Geometry is immutable, source-local and implicitly closed. `ringStart/End` index vertices;
`polygonStart/End` index rings. Clockwise exteriors in Y-down tile coordinates precede their
counter-clockwise holes. `x/y` access without copying; `copyCoordinates`, `copyRingOffsets` and
`copyPolygonOffsets` allocate caller-owned copies. Coordinates outside 0..extent are preserved.
Adjacent overzoomed children share one canonical source geometry; do not upload one mesh per child.
Distinct style layers share the geometry but have independent paint/opacity. Feature IDs can be
null; never deduplicate all missing IDs together. Use source ID, source tile, feature index and
content revision. Polygon clipping, boundary walls and triangulation belong to the host.

Cache request keys include style/policy identity, a semantics marker and a sorted unique requested
tile set; content keys also include canonical source identities and acquired byte digests. Limits
affect whether an operation succeeds, not its successful content. Credentials and sessions are
excluded. NORMAL reads valid raw cache entries, CACHE_ONLY never fetches and RELOAD fetches/replaces.
Malformed cached data is evicted and retried; per-operation limit failures retain valid cached data.
No source substitution or progressive partial result is returned.

The default `ExtrusionLimits` cap 256 requested tiles, 4 MiB encoded input before selective decode,
8 MiB temporary dictionary estimates and 16 MiB estimated retained batch data. Raw network/cache
buffers remain governed by `ResourceLimits.maxTileBytes`; lower that configuration limit when the
host's whole-renderer budget requires it. Decoding is sequential per operation and shares Rentile's
decode permits. `estimatedRetainedBytes` is conservative accounting, not measured RSS. Budget old
batches, concurrent operations, triangulation and GPU buffers separately. Smaller export windows
preserve complete geometry; a single-frame budget failure must fail cleanly. Never fetch a whole
route into retained memory.

The host must still implement the GLES building pass and projection schedule. The projection spike
supports a calibrated globe-to-Mercator geometric transition before building zooms; it does not
qualify production terrain, labels, glTF alignment or mobile GPU performance. Seeks may enter the
destination projection directly. Continue supporting explicit globe and Mercator plans.

The optional probe accepts filenames `paris_15_x_y.pbf`, `manhattan_15_x_y.pbf` and
`tokyo_15_x_y.pbf`. Its times include acquisition, digesting, selective decoding and style binding
through a local transport, with no network or persistent raw store. Compare every ring with the
existing decoder, then qualify frame time, residency, OOM and ANR on mobile in the consumer.
