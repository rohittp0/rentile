# Migrating from 0.10.x to 0.11.0

`0.11.0` is a deliberate minor while Rentile is prerelease. The source tree declares
`VERSION_NAME=0.11.0`; that declaration requests the release but does not prove it has been
published. Upgrade only after `com.rohittp.rentile:kmp:0.11.0` resolves from
`https://maven.rohittp.com` and the release workflow has passed.

Render operations gained a priority. See
[ADR 0032](../adr/0032-rendering-has-a-priority-and-it-is-the-callers.md).

## What changed

Three signatures gained a trailing defaulted parameter:

```kotlin
render(batch, tiles = batch.tiles, priority = RenderPriority.NORMAL)
renderRaw(batch, tiles = batch.tiles, priority = RenderPriority.NORMAL)
render(style, tiles, options, resourceAccess, substitutionPolicy, priority = RenderPriority.NORMAL)
```

`RenderPriority.URGENT` marks a tile the caller is about to present, or one whose absence pauses
presentation. `NORMAL` marks read-ahead. A freed metatile worker goes to an `URGENT` request whenever
one is waiting, and to a `NORMAL` one only when none is; ordering within a level is unchanged FIFO,
and a tile already drawing is never pre-empted.

## What you have to do

**Recompile.** Adding a parameter changes the JVM and klib signatures, so a consumer built against
`0.10.x` does not link against `0.11.0` even though its source compiles unchanged.

**Discard nothing.** Priority is a scheduling decision and reaches nothing else: it does not enter an
output tile's request key or content key, and two tiles rendered at different priorities are
byte-identical. Cached raw resources, cached rendered output and renderer semantics all carry over.

**Nothing else changes by default.** Every existing call site keeps `NORMAL` and therefore keeps its
exact previous behaviour, which is one FIFO queue.

## What to do with it

Mark the tiles someone is waiting for, and only those. The mechanism is relative: a caller that
passes `URGENT` everywhere has one FIFO queue again and has gained nothing. It is worth exactly what
the caller's honesty about its own read-ahead is worth.
