# 0.15.1: Skiko 0.150.2

Rentile now requires Skiko `0.150.2`, replacing `0.148.2`. The same version governs the common
dependency, JVM test runtime, and Android native libraries bundled for `arm64-v8a` and `x86_64`.
The strict dependency constraint is retained so consumers cannot silently mix Skiko versions.

Consumers with a direct Skiko dependency or a host JVM runtime declaration must align it to
`0.150.2`. Rentile remains the Android native-library packaging owner; do not add another copy of
the Skiko native libraries to work around a dependency conflict. Rebuild consumers against the
updated dependency set and verify rendering on the supported platforms.

This release changes no Rentile public API or cache-key definitions. Consumers upgrading from
before `0.15.0` must also follow the [0.15.0 migration guide](0.15.0.md).

Publication is complete only after the release workflow verifies all eight public coordinates
and a fresh consumer resolves the exact version from the public repository.
