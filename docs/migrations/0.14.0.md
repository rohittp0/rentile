# 0.14.0: compact geometry for host scenery

`BasemapRasterizer.acquireSceneryCandidates` returns source-backed point, open-line and polygon
geometry independently of the authored extrusion paint. It reads only vector sources already
owned by the prepared style's extrusion layers. Styles without those sources return no scenery.
No species, height, pedestrian placement or source URL is invented by Rentile.

Pass explicit `SceneryLayerQuery` entries naming the source layer, geometry type and property
whitelist. `SceneryGeometry` provides primitive coordinate/part/polygon accessors in the canonical
source tile's extent. Only whitelisted scalar properties are retained; `propertyKind` distinguishes
missing values from values of the wrong type. IDs may be absent; hosts must deduplicate spatially.

`SceneryLimits` bounds encoded bytes, decoding scratch, retained candidates and requested tiles.
The selective two-pass reader counts coordinates within multipoints before allocating arrays.
Existing global MVT bounds and cancellation apply. Hosts still account for concurrent requests,
placement work, decoded textures and GPU/upload copies: this API is not a process memory budget.

The query and property sets are snapshotted before suspension. Content identity includes the
prepared style, query and acquired-resource revisions. Canonical samples are deduplicated, including
overzoom children. `NORMAL`, `CACHE_ONLY` and `RELOAD` use the existing validated raw cache.
Malformed cached data rolls back partially emitted candidates and byte accounting before recovery;
a safety-limit rejection does not evict valid cached data. Operation/close/style ownership remains
unchanged. Alternate rasterizer implementations inherit an explicit unsupported default.

This minor adds public API without removing the 0.13 surface, and includes the current main-branch
empty-DEM handling. JVM and klib API dumps are updated and reviewed. Nine scenery regressions cover
geometry/holes/properties, canonical overzoom identity, huge multipoints, budgets, cache access,
malformed data, cancellation, rollback and ownership.
