# Style credentials are caller-supplied and optional

The caller supplies API credentials either inside `StyleInput` URLs or, only when necessary, through an optional credential provider; Rentile has no required standalone API-key argument. Preparation extracts embedded credentials into ephemeral secret state and removes them from canonical URLs, persisted style/resource records, digests, cache identity, content keys, diagnostics, exceptions, metrics, and Corpus Reports. An extracted credential may decorate an otherwise keyless resource only when its exact HTTPS origin and credential-parameter name match; it is never inferred across origins. Session context remains separately caller-supplied, and every origin-changing redirect removes all sensitive decorations.
