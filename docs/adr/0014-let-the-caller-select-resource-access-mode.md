# Let the caller select resource access mode

Each preparation or render operation may select a non-content `ResourceAccessMode`: `NORMAL` uses fresh raw entries and revalidates stale entries, `CACHE_ONLY` uses any integrity-valid cached bytes without transport access, `RELOAD` fetches unconditionally while replacing an existing entry only after successful validation, and `CACHE_SUBSTITUTE_THEN_NETWORK` lets substitution-enabled Output Tile preparation try exact cache, then cache-only synthesis, before normal exact acquisition. The latter remains caller-controlled recovery: Rentile returns a substituted Prepared Batch and the caller decides when to invoke `retryExact`. The mode never enters output identity; the frozen resource digests do, allowing callers to implement offline use, latency-first degradation, and explicit refetch without Rentile owning recovery timing.
